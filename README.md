# Sorting & Filtering Data — Sales Analysis in Power BI

## Project Overview
This project demonstrates how sorting and filtering techniques in Microsoft Power BI can help a sales manager identify high-value transactions and underperforming products. The report uses sales data to explore revenue, profit, product performance, and regional sales.

## Objectives
- Identify high-value sales transactions by sorting revenue in descending order.
- Analyse transaction-level revenue and profit.
- Examine product performance using revenue, profit, and profit margin.
- Explore sales performance across different regions.
- Apply sorting and filtering techniques to extract meaningful business information.

## Tools Used
- Microsoft Power BI Desktop
- Microsoft Excel

## Dataset
**Dataset:** `sales_analysis_dataset.xlsx`

The dataset contains sales information, including:
- Transaction ID
- Product
- Region
- Revenue ($)
- Profit ($)
- Quantity
- Margin (%)
- Discount (%)

## Project Implementation

### 1. High-Value Transactions
A table visual is used to display transaction details. Sorting the Revenue ($) column in descending order places the highest-value transactions at the top, making them easier to identify.

### 2. Product Performance Analysis
Product performance is examined using revenue, profit, and profit margin. These measures help compare products and identify those that may require further investigation.

### 3. Regional Sales Analysis
Sales revenue is compared across regions to understand differences in regional performance.

### 4. Revenue and Profit Analysis
Visuals are used to compare revenue and profit and understand how sales performance varies across products and transactions.

### 5. Sorting and Filtering
Sorting arranges data in ascending or descending order, while filtering narrows the displayed data to selected products, regions, or transaction values. Together, these techniques make the analysis more focused and useful for business decisions.

## Key Outcomes
- Identified high-value transactions by sorting revenue.
- Compared product revenue and profitability.
- Explored regional sales performance.
- Used Power BI visuals to make sales information easier to understand.
- Demonstrated how sorting and filtering support data-driven business analysis.

## How to Run the Project
1. Install and open Microsoft Power BI Desktop.
2. Open `Sorting & Filtering Data.pbix`.
3. If prompted, locate `sales_analysis_dataset.xlsx`.
4. Refresh the data if required.
5. Explore the report visuals and use the Filters pane to analyse different products, regions, and transactions.
